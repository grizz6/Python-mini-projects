# Python-mini-projects

Projects
911 Call Data
Data: 911.csv
EDA on emergency 911 call records. Extracts call reason (EMS, Fire, Traffic) from the title field, then analyzes call volume by hour, day, and month. Produces countplots, time series line plots, day-vs-hour heatmaps, and a correlation matrix. Ends with a linear regression discussion on predicting call volume from time features.
**Libraries: pandas, numpy, matplotlib, seaborn, scikit-learn**

Brain Tumor Project
Data: brain_tumor_dataset.csv
Predicts patient survival rate from brain tumor characteristics (age, tumor size, tumor type, growth rate, treatment history). Covers data cleaning, outlier handling via IQR capping, label encoding of categorical features, and StandardScaler normalization. Includes correlation heatmap, tumor size distribution, survival rate by tumor type boxplots, and treatment breakdowns. Trains a linear regression model to predict survival rate.
**Libraries: pandas, numpy, matplotlib, seaborn, scikit-learn**
